## 4. 四态规范

| 状态 | 表现 | 触发 |
|---|---|---|
| loading | 表格/列表 `v-loading`；详情页骨架屏 | 请求发出 |
| empty | `el-empty` + 主行动按钮（如"去逛逛"/"新增类型"） | `code=0` 且列表为空 |
| error | `EmptyState type="error"` + 重试按钮 | 请求异常 / `code != 0` |
| 正常 | 渲染数据 | 默认 |

**规则**：四态互斥，同一时刻只渲染一种；error 态必须可重试；empty 态必须给出下一步动作。

## 5. 状态与数据流约定

- `stores/user.js`：`token` / `userInfo` / `role`，持久化 key `mall_token`、`mall_user`；`isAdmin` getter；`logout()` 清本地 + 跳登录。
- `stores/cart.js`：**只存角标数量**，由 `GET /front/cart` 的 `totalQuantity` 刷新；不做本地购物车缓存。
- `composables/useListQuery.js`：统一列表查询，产出 `list / total / loading / error / query / load() / reset() / setPage()`。
- `utils/request.js`：解包 `data`；`401/2001/2002` → 清 token + 按路径跳 `/admin/login` 或 `/login?redirect=`；`2003` 提示；同屏 `ElMessage` 去重。
- 订单动作：**只渲染 `actions[]`**，前端不写状态判断分支。
