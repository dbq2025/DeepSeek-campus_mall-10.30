# 视觉规范（阶段 4.5 改版后）

> 版本：v1.0　日期：2026-10-31　适用：`codes/frontend/src/**`
> 配套：`design/42-界面视觉改版计划.md`（方案）、`design/40-页面与交互.md`（页面映射）

---

## 1. 设计定调

**克制的现代感**：一个强调色（靛蓝）+ 中性灰阶（slate）+ 两级表面（画布/卡片）+ 轻量动效（≤240ms）。

三条可检验标准：

1. 强调色只用于主行动、选中态、关键数字、链接，页面中占比 < 8%。
2. 任何页面都能分出「画布 → 卡片 → 卡片内区块」三层。
3. 可点元素必有 hover 与 `focus-visible` 反馈。

## 3. 排版

字体栈（系统字体，不加载 Web 字体）：

```
-apple-system, BlinkMacSystemFont, "Segoe UI", "PingFang SC",
"Hiragino Sans GB", "Microsoft YaHei", "Helvetica Neue", Arial, sans-serif
```

| 用途 | 桌面 | 移动 | 字重 | 字距 |
|---|---|---|---|---|
| Hero 标题 | 40px | 26px | 700 | -0.02em |
| 页面标题 | 24px | 20px | 700 | -0.01em |
| 区块标题 | 20px | 18px | 600 | -0.01em |
| 卡片标题 | 16–17px | 16px | 600 | 0 |
| 正文 | 14px | 14px | 400 | 0 |
| 次要说明 | 13px | 13px | 400 | 0 |
| 标签/角标 | 12px | 12px | 500 | 0.01em |
| 数字大字 | 28–30px | 24px | 700 | -0.02em |

- 所有金额、销量、库存、统计值加 `font-variant-numeric: tabular-nums`（类 `.num` 或 `.price`）。
- 金额一律字符串传输与展示，禁止浮点运算。

## 5. 动效

| 场景 | 时长 | 曲线 |
|---|---|---|
| 颜色/边框 | 140ms | ease-out |
| 卡片 hover（`translateY(-4px)`） | 220ms | `cubic-bezier(.22,.61,.36,1)` |
| 图片 hover（`scale(1.04)`） | 420ms | ease-out |
| 按钮按下（`translateY(1px)`） | 80ms | ease-out |
| 弹窗/抽屉 | 240ms | `cubic-bezier(.22,.61,.36,1)` |

`prefers-reduced-motion: reduce` 下关闭位移与缩放，仅保留透明度变化。

## 7. 响应式

| 视口 | 前台商品网格 | 详情页 | 后台 |
|---|---|---|---|
| ≥1280 | 4 列 | 图 1fr + 信息 420px | 侧栏 232px |
| 1024–1279 | 3 列 | 双栏 | 侧栏 232px |
| 768–1023 | 2 列 | 双栏 | 侧栏 64px 图标栏 |
| 480–767 | 2 列 | 单栏 | 侧栏 64px，表格横向滚动 |
| <480 | 2 列（<360 单列） | 单栏 | 同上 |

**后台目标视口 ≥1024**。窄屏下表格在容器内横向滚动、操作列固定，不隐藏列。

## 8. 可访问性

- 键盘焦点：`0 0 0 3px rgba(79,70,229,.18)`，不使用 `outline: none` 裸奔。
- 对比度（对白底）：`text-1` 18.2:1、`text-2` 7.6:1、`text-3` 4.8:1、主色 6.3:1。
- 颜色不作为唯一信息载体：状态标签同时有文案。
- 图标按钮保留 `aria-label`。

## 9. 施工约束（改版期间）

| 层级 | 允许 | 示例 |
|---|---|---|
| L1 样式 | 任意 `<style>`、class、CSS 变量、`:deep()` | 圆角、阴影、间距 |
| L2 展示结构 | 纯展示包裹层、DOM 顺序、静态文案/图标、纯展示 props | 指标卡图标、Hero 装饰层 |
| L3 逻辑 | **禁止** | 状态、接口、路由、store、事件、校验、字段名 |

`api/ mock/ stores/ router/ composables/ utils/` 在本次改版中 **diff 为 0**（可用 `git diff` 验证）。
