### 1.3 三条硬约束：如何保证「功能不变」

改造按三层授权执行，**越界即停**：

| 层级 | 允许 | 示例 | 审批 |
|---|---|---|---|
| **L1 样式** | 任意修改 `<style>`、新增 class、CSS 变量、`:deep()` | 卡片圆角 8→16、表头底色 | 无需 |
| **L2 展示结构** | 新增**纯展示**包裹层、调整 DOM 顺序（不跨表单）、替换展示元素、增加静态文案/图标、调整纯展示 props（`size`/`round`/`shadow`/`effect`） | 指标卡加图标块、Hero 加一行标签 | 阶段验收时说明 |
| **L3 逻辑** | **禁止**：`script setup` 内任何状态、接口、路由、store、事件、校验、字段名；`v-if`/`v-for` 的数据条件；`el-form` 校验规则 | — | 一律不做 |

> **唯一例外**：`main.js` 增加一行 `import './assets/styles/element-theme.css'`（样式引入，非逻辑）。会在提交说明中单列。

## 3. 设计方向

### 3.1 定调

> **克制的现代感**：用一个强调色建立识别，用中性灰阶承载信息，用留白与阴影制造层次，用 200ms 内的微交互提供反馈。

对应三个可检验的特征：

- **看颜色**：除靛蓝外，界面只剩灰阶与语义色（红/绿/橙）；强调色占比 < 8%。
- **看层次**：任何页面都能一眼分出「画布 → 卡片 → 卡片内区块」三层。
- **看反馈**：鼠标移到任何可点元素上，0.15s 内必有可见变化；键盘 Tab 必有焦点环。

### 3.2 参考坐标（开源项目 → 借鉴点 → 落点）

| 参考项目 | 借鉴的设计理念 | 在本项目的落点 |
|---|---|---|
| **shadcn/ui** | 中性色阶 + 单一强调色；1px 低对比描边替代重阴影；组件"可组合"而非"可配置" | 全局色板、卡片与表单的描边策略 |
| **Vercel Geist** | 排版层级严格（4 级）；标题负字距；数字用 tabular-nums | 字号体系、价格与统计数字 |
| **Ant Design Pro** | 后台信息架构：指标卡 → 图表卡 → 明细表；卡片头统一 | 数据概览、数据统计 |
| **Soybean Admin**（Vue3 后台） | 深色侧栏 + 浮起内容区；选中项用渐变与光晕而非纯色块 | AdminLayout 侧栏与选中态 |
| **Tailwind UI / Untitled UI** | 圆角与阴影分层（xs/sm/md/lg）；表单控件统一 36px 高、10px 圆角 | 通用组件规格表（§5.9） |
| **Linear** | 150–220ms 的动效节奏；focus ring；hover 只做"轻微抬升" | 全局动效与可访问性 |
| **京东 / 天猫**（电商惯例） | 价格红、价格字号跳两级、角标、"¥"缩小 | ProductCard 与详情页价格区 |

> 只借"设计理念"，不搬代码、不引依赖、不做像素级复刻。

### 3.3 五条视觉原则

1. **一个强调色**：靛蓝只用于主行动、选中态、关键数字、链接；其余一律灰阶。禁止大面积彩色背景。
2. **两级表面**：`canvas #F6F7FB` 上浮 `surface #FFFFFF`；用「1px 极浅边框 + 一档阴影」区分，而不是到处画深边框。
3. **留白优先**：区块间距 24/32/40，卡内 20/24；密度靠**对齐**获得，不靠压缩间距。
4. **数字优先**：价格、金额、统计值用 `tabular-nums`，字号比同级文字大 1–2 级，`¥` 符号缩小到 0.75em。
5. **反馈可感知**：hover 抬升 ≤4px、变色 140ms、focus 3px 环、按下下压 1px；不做无意义的循环动画。

### 4.2 Element Plus 主题桥（技术关键点）

**为什么必须单独做一层**：EP 的颜色家族不是运行时计算的，而是构建时写死在 CSS 里的静态变量。只改 `--el-color-primary`，会出现「按钮是靛蓝、hover 变回默认蓝、plain 背景还是浅蓝」的断层。

因此新增 `src/assets/styles/element-theme.css`，按「30/50/70/80/90% 与白混合」生成完整家族：

```css
:root {
  --el-color-primary: #4f46e5;
  --el-color-primary-light-3: #847ded;
  --el-color-primary-light-5: #a7a2f2;
  --el-color-primary-light-7: #cac7f7;
  --el-color-primary-light-8: #dcdafa;
  --el-color-primary-light-9: #edecfc;
  --el-color-primary-dark-2: #3f38b7;

  --el-color-success: #12b76a;
  --el-color-warning: #f79009;
  --el-color-danger: #f04438;
  --el-color-error: #f04438;
  --el-color-info: #64748b;

  --el-text-color-primary: #0f172a;
  --el-text-color-regular: #475569;
  --el-text-color-secondary: #64748b;
  --el-text-color-placeholder: #94a3b8;

  --el-border-color: #e2e8f0;
  --el-border-color-light: #eef2f7;
  --el-border-color-lighter: #f1f5f9;
  --el-fill-color-light: #f8fafc;
  --el-fill-color-blank: #ffffff;

  --el-border-radius-base: 10px;
  --el-border-radius-small: 8px;
  --el-border-radius-round: 999px;

  --el-font-family: -apple-system, BlinkMacSystemFont, 'Segoe UI', 'PingFang SC',
    'Hiragino Sans GB', 'Microsoft YaHei', 'Helvetica Neue', Arial, sans-serif;
  --el-box-shadow-light: 0 8px 24px -16px rgba(15, 23, 42, 0.18);
}
```

同步覆盖 `--el-color-{success,warning,danger,info}-light-9` 与 `-dark-2`，保证 `el-tag`、`el-alert`、`el-button plain` 的浅底与按下态一致。

**引入顺序**（决定成败）：`element-plus/dist/index.css` → `variables.css` → `element-theme.css` → `base.css`。最后引入的 `base.css` 才能压住 EP 的 `body` 字号与表格基础样式。

### 4.6 动效

| 场景 | 时长 | 曲线 | 效果 |
|---|---|---|---|
| 颜色/边框变化 | 140ms | `ease-out` | 文字色、边框、背景 |
| 卡片 hover | 220ms | `cubic-bezier(.22,.61,.36,1)` | `translateY(-4px)` + shadow-hover |
| 图片 hover | 420ms | `ease-out` | `scale(1.04)` |
| 按钮按下 | 80ms | `ease-out` | `translateY(1px)` |
| 弹窗/抽屉 | 240ms | `cubic-bezier(.22,.61,.36,1)` | 淡入 + 4px 上移 |
| 骨架屏 | 1.4s | `ease` | 渐变扫光（保留现有） |

- 全局 `@media (prefers-reduced-motion: reduce)` 关闭位移与缩放，仅保留透明度变化。
- 不做滚动揭示（scroll-reveal）、不做自动轮播、不做循环呼吸灯。

### 4.7 图标与插画

- 图标：**沿用** `@element-plus/icons-vue`（已安装，全局注册），不引第三方图标库。
- 空状态：内联 SVG（96px 渐变圆底 + 线性图标），不引插画库、不引外链图片。

### 8.3 视觉走查清单（逐页 12 项）

1. 强调色唯一：全页只有靛蓝一种强调色，无 EP 默认蓝残留

6. 间距节奏：区块 24/32，卡内 20/24，控件间 12

8. 交互：可点元素均有 hover 与 `focus-visible`，按钮有 active 反馈
9. 四态：loading / empty / error / 正常 视觉一致且互斥
10. 响应式：1440 / 1024 / 390 无横向滚动（后台表格容器内滚动除外）
11. 对比度：正文 ≥ 4.5:1，次要文字 ≥ 3:1

## 10. 风险与回滚

| 项 | 说明 |
|---|---|
| 回滚粒度 | 每阶段一次提交，`git revert <sha>` 即可退回该阶段；P0 为纯令牌，单独 revert 不影响功能 |
| 兼容策略 | `variables.css` 保留全部旧变量名（只换值），旧组件不改也能生效，降低"改一半"风险 |
| 最坏情况 | 视觉方案整体不通过：revert 6 个 `style` 提交，代码回到 `5895cf7` 的功能完成态，零数据损失 |
| 不做的事 | 不改依赖、不改构建配置、不动 mock 与接口，因此不存在"跑不起来"的风险面 |
