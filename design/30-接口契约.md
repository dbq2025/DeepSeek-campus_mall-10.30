# 阶段 4 · 接口契约 v1.0

> **本文档是前端 mock、前端 api 层、后端 Controller 的唯一事实来源。**
> 改字段先改本文档，再改 mock，再改代码；禁止"先写代码再补契约"。
> 编号规则：`<域>-<序号>`，一经分配不复用。

---

## 0. 通用约定

| 项 | 约定 |
|---|---|
| 前缀 | 后端 `context-path = /api`，前端 `VITE_API_BASE=/api`；下文路径均省略 `/api` |
| 认证 | 请求头 `Authorization: Bearer <token>` |
| 成功 | `HTTP 200` + `{ "code": 0, "msg": "ok", "data": ... }` |
| 业务失败 | `HTTP 200` + `code != 0`，`msg` 为可直接展示的中文 |
| 认证/权限失败 | `HTTP 401` / `403`（由全局异常处理器返回） |
| 分页入参 | `page`（从 1 开始，默认 1）、`size`（默认 10） |
| 分页出参 | `{ records: [], total, current, size, pages }` |
| 时间 | `yyyy-MM-dd HH:mm:ss` 字符串 |
| **ID** | **一律字符串**（雪花 ID 超出 JS 安全整数），禁止 `parseInt` |
| **金额** | **一律字符串**，两位小数（如 `"99.00"`），禁止浮点运算 |
| 空值 | 集合返回 `[]` 不返回 `null`；对象字段缺失返回 `null` |

### 0.1 错误码（与 `ResultCode` 一一对应）

| code | 含义 | 前端处理 |
|---|---|---|
| 0 | 成功 | — |
| 1001 | 参数校验失败 | 直接展示 `msg` |
| 1002 | 请求体格式错误 | 直接展示 `msg` |
| 2001 | 未登录或缺少令牌 | 清 token + 跳登录 |
| 2002 | 令牌无效或已过期 | 清 token + 跳登录 |
| 2003 | 无权限 | 提示，不跳转 |
| 2004 | 账号或密码错误 | 表单内提示 |
| 3001 | 库存不足 | 展示 `msg`，刷新列表 |
| 3002 | 当前状态不允许该操作 | 展示 `msg`，刷新详情 |
| 3003 | 资源不存在 | 展示 `msg` |
| 3004 | 请勿重复操作 | 展示 `msg` |
| 3005 | 商品已下架 | 展示 `msg` |
| 5000 | 系统异常 | 展示 `msg` |

### 0.2 枚举字典

| 枚举 | 取值 |
|---|---|
| `user.role` | `USER` / `ADMIN` |
| `product.status` | `1` 上架 / `0` 下架 |
| `orders.status` | `0` 待付款 / `1` 待发货 / `2` 待收货 / `3` 已完成 / `4` 已取消 |
| `actions[].action` | `pay` / `cancel` / `confirm` / `ship` |

`statusText` 由后端给出，前端**只展示不自造**；`actions[]` 由后端按当前状态与角色计算，前端**只渲染不判断**。

## 1. 认证 AUTH（5）

### AUTH-01 用户登录
`POST /auth/login`

| 入参 | 类型 | 必填 | 说明 |
|---|---|---|---|
| username | string | 是 | 登录名 |
| password | string | 是 | 明文，HTTPS/本地传输 |

出参 `LoginVO`：

| 字段 | 类型 | 说明 |
|---|---|---|
| token | string | JWT |
| userInfo | UserVO | 见下 |

`UserVO`：`id`(string) `username` `nickname` `email` `phone` `avatar` `role`

### AUTH-02 用户注册
`POST /auth/register` — 入参 `username`(4–20) `password`(6–20) `nickname`(≤20) `email`(可空)；出参同 AUTH-01，注册即登录。

### AUTH-03 管理员登录
`POST /auth/admin/login` — 入参同 AUTH-01；`role != ADMIN` 返回 `2003`。出参同 AUTH-01。

### AUTH-04 当前用户
`GET /auth/me` → `UserVO`（需登录，用于刷新页面后校验 token）

### AUTH-05 退出登录
`POST /auth/logout` → `null`（无状态 JWT，服务端仅记录日志，前端清本地）

## 2. 前台商品 FPRD（3）

### FPRD-01 商品分页
`GET /front/products`

| 入参 | 类型 | 必填 | 说明 |
|---|---|---|---|
| keyword | string | 否 | 匹配 name / subtitle |
| categoryId | string | 否 | 类型筛选 |
| sort | string | 否 | `default` / `price_asc` / `price_desc` / `sales_desc` / `new` |
| page / size | number | 否 | 分页 |

出参 `PageResult<ProductItem>`，仅返回 `status=1` 且未删除的商品。

`ProductItem`：

| 字段 | 类型 | 说明 |
|---|---|---|
| id | string | 主键 |
| name | string | 商品名 |
| subtitle | string | 副标题 |
| mainImage | string | 主图路径 |
| price | string | 售价 |
| stock | number | 库存 |
| sales | number | 销量 |
| categoryId | string | 类型 ID |
| categoryName | string | 类型名（联表带出） |

### FPRD-02 商品详情
`GET /front/products/{id}` → `ProductDetailVO` = `ProductItem` + 下列字段：

| 字段 | 类型 | 说明 |
|---|---|---|
| specJson | string/null | 规格定义 JSON 字符串，空表示无规格 |
| detail | string | 详情富文本 |
| createTime | string | 上架时间 |
| favorited | boolean | 当前用户是否已收藏（未登录为 `false`） |

`status != 1` 返回 `3005`。

### FPRD-03 类型列表
`GET /front/categories` → `CategoryItem[]`：`id` `name` `sort`（按 `sort` 升序）

## 3. 购物车 CART（5）

### CART-01 购物车列表
`GET /front/cart` → `CartVO`

| 字段 | 类型 | 说明 |
|---|---|---|
| items | CartItem[] | 明细 |
| totalQuantity | number | 全部行数量之和（角标用） |
| totalAmount | string | 全部行小计之和（仅预览，下单以后端为准） |

`CartItem`：`id` `productId` `productName` `mainImage` `price`(当前售价) `quantity` `specText` `stock` `productStatus`(1/0)

### CART-02 加入购物车
`POST /front/cart` — 入参 `productId` `quantity`(≥1) `specText`(有规格时必填)；同商品同规格累加数量。出参 `CartItem`。

### CART-03 修改数量
`PUT /front/cart/{id}` — 入参 `quantity`(≥1)；超库存返回 `3001`。出参 `CartItem`。

### CART-04 删除一行
`DELETE /front/cart/{id}` → `null`

### CART-05 清空购物车
`DELETE /front/cart` → `null`

## 4. 订单 FORD（6）

### FORD-01 创建订单
`POST /front/orders`

| 入参 | 类型 | 必填 | 说明 |
|---|---|---|---|
| fromCart | boolean | 是 | `true` 购物车下单，`false` 立即购买 |
| cartIds | string[] | 条件 | `fromCart=true` 时必填 |
| items | OrderItemInput[] | 条件 | `fromCart=false` 时必填：`productId` `quantity` `specText` |
| receiverName | string | 是 | ≤50 |
| receiverPhone | string | 是 | 11 位手机号 |
| receiverAddress | string | 是 | ≤255 |
| remark | string | 否 | ≤200 |

出参 `CreateOrderVO`：`orderId`(string) `orderNo`(string) `payAmount`(string)

副作用：扣库存（`WHERE stock >= n`）、写订单+明细快照、清理已下单购物车行。库存不足 `3001`，下架 `3005`。

### FORD-02 我的订单分页
`GET /front/orders` — 入参 `status`(可空，空=全部) `page` `size` → `PageResult<OrderItemVO>`

`OrderItemVO`：

| 字段 | 类型 | 说明 |
|---|---|---|
| id | string | 订单 ID |
| orderNo | string | 业务单号 |
| status | number | 0–4 |
| statusText | string | 中文状态 |
| payAmount | string | 实付 |
| createTime | string | 下单时间 |
| items | OrderProductVO[] | `productId` `productName` `productImage` `price` `quantity` `specText` `totalAmount` |
| actions | ActionVO[] | `{ action, label, type }`，`type` 为 Element Plus 按钮类型 |

### FORD-03 订单详情
`GET /front/orders/{id}` → `OrderDetailVO` = `OrderItemVO` + `totalAmount` `receiverName` `receiverPhone` `receiverAddress` `remark` `trackingNo` `payTime` `shipTime` `finishTime` `cancelTime` `cancelReason`。非本人订单返回 `2003`。

### FORD-04 支付（模拟）
`POST /front/orders/{id}/pay` → `null`；合法源状态 `0`；已支付幂等返回成功，其余 `3002`。

### FORD-05 取消订单
`POST /front/orders/{id}/cancel` — 入参 `reason`(可空，默认"用户取消")；合法源状态 `0`；回补库存。

### FORD-06 确认收货
`PUT /front/orders/{id}/confirm` → `null`；合法源状态 `2`。

## 7. 后台商品 ADM-PRD（7）

| 编号 | 方法与路径 | 入参 | 出参 |
|---|---|---|---|
| PRD-01 | `GET /admin/products` | `keyword` `categoryId` `status` `page` `size` | `PageResult<ProductVO>` |
| PRD-02 | `GET /admin/products/{id}` | — | `ProductDetailVO`（含下架商品） |
| PRD-03 | `POST /admin/products` | `ProductForm` | `{ id }` |
| PRD-04 | `PUT /admin/products/{id}` | `ProductForm` | `null` |
| PRD-05 | `PUT /admin/products/{id}/status` | `status` 0/1 | `null` |
| PRD-06 | `PUT /admin/products/status` | `ids[]` `status` | `null`（批量） |
| PRD-07 | `DELETE /admin/products/{id}` | — | `null`（逻辑删除，已有订单仍可查） |

`ProductVO` = `ProductItem` + `status` `createTime`
`ProductForm`：`categoryId` `name` `subtitle` `mainImage` `price` `stock` `specJson`(可空) `detail` `status`

`specJson` 校验：必须是 `[{"name":"...","values":["..."]}]` 形态的 JSON 数组字符串，名称与值均非空且不重复。
