## 5. 运行方式

```bash

mysql --default-character-set=utf8mb4 -uroot -p1234 < codes/backend/src/main/resources/db/schema.sql
mysql --default-character-set=utf8mb4 -uroot -p1234 < codes/backend/src/main/resources/db/data.sql

# 2. 后端（8080，context-path=/api）

cd codes/frontend && npm run dev
```

## 6. 已知限制

1. **导入种子数据必须带 `--default-character-set=utf8mb4`**：Windows 版 mysql 客户端默认 `character_set_client=gbk`，直接重定向 UTF-8 文件会报 `Data too long for column 'nickname'`。
2. `/files` 代理只在 dev 生效；生产同源部署时需由 Nginx 或后端直接处理 `/files/**`，或把 `mainImage` 改存 `/api/files/...`。
3. 分类分页的 `productCount` 为逐行 count（单页 ≤100，量级可接受），未做一次 group by 聚合。
4. 取消订单只回补库存、不回退销量（D1 选择「支付成功才计销量」，取消发生在支付前，无需回退）。
5. 上传目录 `mall.upload.dir=./upload` 相对启动目录解析；换目录启动需同步迁移已有图片。
